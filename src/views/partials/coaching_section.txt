The snippet you saw is using a higher-order function (a function that returns another function). In JavaScript, this is a powerful principle because it lets us wrap behavior around other functions. Here, the wrap function takes any route handler and ensures that if it returns a rejected promise or throws an error, it gets caught and passed to Express’s error middleware.

So the principle at play is abstraction and error handling with higher-order functions. Instead of repeating try/catch in every route, you abstract it once and reuse it everywhere. That’s why it’s useful for asynchronous code — it keeps things clean and consistent.

Great honesty, Teddy — that’s exactly the spirit of this coaching session. Let me give you a concrete example outside of Express.

Imagine you’re working with arrays in JavaScript. Functions like .map(), .filter(), and .reduce() are all higher-order functions because they take another function as an argument. For example:

js
const numbers = [1, 2, 3, 4];
const doubled = numbers.map(num => num * 2);
console.log(doubled); // [2, 4, 6, 8]
Here, .map() is a higher-order function. Instead of writing a loop every time, you pass in a function (num => num * 2) and let .map() handle the iteration. This simplifies your code and makes it more expressive.

So the principle is the same: abstract away repetitive logic by passing functions into other functions.

Now let’s move into Topic 3: EJS Partials and Pages. In your server.js, you’re rendering views like res.render('organizations', { title }). That means you’re using EJS templates. A common best practice is to use partials (like a shared header or footer) so you don’t repeat code across pages.

Here’s a simple example of an EJS partial:

ejs
<!-- views/partials/header.ejs -->
<header class="site-header">
  <h1><%= title %></h1>
</header>
And then in a page:

ejs
<!-- views/home.ejs -->
<%- include('partials/header') %>
<p>Welcome to the homepage!</p>

That’s a really insightful way to put it, Teddy — yes, partials make it easier to handle mistakes because you only need to fix something once in the shared file, and every page that includes it benefits automatically. It’s also about maintainability and consistency: headers, footers, or navigation menus often repeat across pages, so partials prevent duplication and keep everything aligned.
